## 🚀 Summary

We are proud to announce the first stable release of **AgentAuth**, the open standard for Agentic Identity and Delegation.
This release marks the transition from "Prototype" to **"Production-Ready Protocol"**.

It introduces the **Dual-Protocol Architecture**:
1.  **AAP-001 (Identity)**: Self-sovereign cryptographic identity for AI agents.
2.  **AAP-002 (Delegation)**: Chained "Power of Attorney" tokens with embedded fiduciary logic.

## 🌟 Key Features

-   **Degraded Mode**: Verify authority without a central server (critical for industrial/military edge).
-   **Legal Logic**: Tokens support `liability_cap`, `dual_control`, and `jurisdiction` constraints.
-   **Clean Room Implementation**: 100% free of legacy IP (Siemens/Gimel purged). Licensed under MIT.
-   **Strategy Pack**: Includes the full manuscript of *"The Agent's Signature"* and the Investor Strategic Advisory.
