# AgentAuth v1.1.0-beta: The Identity Update

**Release Date:** January 6, 2026
**Version:** v1.1.0-beta

---

## 🚀 Summary

This release brings critical enhancements to Agent Identity and Governance, introducing **Dynamic Identity Verification** and **MCP Governance**.

## 🌟 New Features

### 1. Dynamic Identity (Phase 8/22)
-   **Dynamic JWKS**: AgentAuth can now dynamically fetch and cache JSON Web Key Sets (JWKS) from trusted external issuers (e.g., Azure AD, Keycloak).
-   **OBO Support**: Enables On-Behalf-Of flows where agents present identity assertions signed by 3rd-party providers.

### 2. Model Context Protocol (MCP) Support (Phase 24)
-   **MCP Gateway**: Connects AgentAuth to the Model Context Protocol ecosystem.
-   **Governance**: Enforce AgentAuth policies on tool execution and resource access within MCP.

### 3. Stability & Developer Experience
-   **Degraded Mode**: Fixed and verified degraded mode startup (no DB/Redis required).
-   **Test Suite**: 100% pass rate on unit and integration tests (including Policy Engine).
-   **Compliance**: `jwks_uri` added to OIDC Discovery endpoint.

## 🛠 Fixes

-   **Policy Engine**: Refactored `Registry` to support `Store` interface with Context (fixed build failures).
-   **Discovery**: `/.well-known/agentauth-configuration` now correctly advertises `jwks_uri`.
-   **Documentation**: Updated `README.md` with actionable Quick Start commands.
