# AAP-001 (Placeholder Extract)

## 1. Introduction
AgentAuth Core Protocol describes mechanisms for delegation, policy evaluation, audit traceability and revocation. (Placeholder text.)

## 2. Policy Bundle Integrity
Implementations MUST link each policy bundle to the previous via a cryptographic hash to ensure chain integrity.
A client SHOULD be able to query provenance metadata including bundle hash, timestamp, and issuer identity.

## 3. Delegation & Revocation
Each delegation artifact MUST contain a reference to its parent delegation or root authority.
Revocation entries MUST NOT be alterable once appended.
Implementations SHOULD provide an externally verifiable anchor for revocation chains.

## 4. Audit Logging
Audit events MUST capture decision inputs sufficient for deterministic replay.
Audit chain hashes MAY be anchored to external trusted timestamp services.

## 5. Replay Protection
Token creation endpoints MUST reject previously seen nonces or identifiers to prevent replay.

## 6. Cryptographic Requirements
Signatures MUST employ algorithms with public verifiability.
HMAC symmetric-only schemes SHOULD NOT be used for cross-tenant verification contexts.
